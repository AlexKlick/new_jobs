## Phase 1: Job Status Checker

**Goal:** Verify job postings are still active

**Status:** COMPLETE (2026-03-27)

**Key Deliverables:**
- `job_status_checker.py` - Status detection module
- `api_server.py` - FastAPI backend with status endpoints
- `StatusChecker.tsx` - UI component with status column

**API Endpoints:**
- `POST /api/jobs/:index/check-status`
- `POST /api/jobs/check-all`
- `GET /api/jobs/:index/status`

**Verification:**
- Check status for active job (expect ACTIVE)
- Check status for closed job (expect CLOSED)
- Batch check multiple jobs

## Phase 2: Markdown Editor

**Goal:** Enable inline editing of resume/cover letter markdown

**Status:** COMPLETE (2026-03-26)

- Updated `DocumentViewer.tsx` with edit mode
- API endpoints for saving markdown

**API Endpoints:**
- `PUT /api/jobs/:index/resume`
- `PUT /api/jobs/:index/cover-letter`

**Verification:**
- Edit resume markdown
- Preview changes
- Save and verify file updated
- Cancel edit without saving

**Verification:**

- Watch progress updates - Done (GenerationProgress component)
