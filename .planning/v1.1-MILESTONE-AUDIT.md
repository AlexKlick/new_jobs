### Minor Integration Issues (Non-blocking)

**1. Vite dev proxy not configured (low severity)**
- `skills/api.ts` uses relative `/api/skills` — correct for production
- Dev without proxy: requests go to `localhost:5173/api/skills` instead of `localhost:8080`
- Mitigation: Add to `vite.config.ts`:
  ```typescript
  server: {
    proxy: { '/api': { target: 'http://localhost:8080', changeOrigin: true } }
  }
  ```
- Impact: Skills editor only affected in dev without the proxy config

**2. SessionInfo type missing skill_job_type (low severity)**
- `SessionInfo` interface in SessionSelector.tsx omits `skill_job_type`
- Runtime works correctly (ChatInterface uses `any` typing when loading sessions)
- Impact: TypeScript type safety only
